# GM MINI BAR — SPP 군단

[English](README.md) · 한국어

**1.0.0 / 한글 서버 퀘스트 응답 호환 수정**

**v1.0.0**은 한글 서버 응답의 `지도`, `(입장): 번호)`, 검색 종료 문구를 인식하도록 수정했습니다. 조건 찾기·시작 위치·종료 위치에 공통 적용하며 영문 응답도 지원합니다. 애드온 폴더를 교체한 뒤 UI를 다시 불러오세요. 한글 SQL 복원은 필요하지 않습니다. 확인 범위는 GAME_TEST.md에 기록합니다.

SPP Legion V2 Praevius, WoW **7.3.5.26972 / Interface 70300**용 GM 애드온입니다. 기존 리치왕 GM MINI BAR의 메뉴 배치, 검정·금색 패널, 2열 편의 기능, 주문·아이템·순간이동 화면 구성을 기준으로 군단 API와 데이터를 연결했습니다. 설치 폴더는 `GMminibar` 하나입니다.

RC2에서는 직업 주문 분류를 다시 연결하여 누락된 전문화·특성 주문을 포함하고, 전문기술 주문이 다른 직업 목록에 섞이는 문제를 수정했습니다. 아이템은 던전·공격대·세트 분류와 2열 목록, 수량 입력 창을 제공합니다. 순간이동은 6개 분류와 대륙·지역/도시·목적지·유형·권장 레벨·진영 표로 복원했습니다.

RC4는 기존 리치왕 통합 가방의 전체 구성을 기준으로 선택·높이 조절·파괴·정렬·판매 도구줄과 하단 검색·아이템 고정·빈칸·소지금·장착 가방 4칸을 복원했습니다. 품질/종류 조건, 실행 전 대상 확인, 캐릭터별 위치 고정과 고정 칸을 보존하는 자동/수동 정렬을 제공합니다. 기본은 8열·3줄이며 한 줄씩 높이를 조절하고 휠로 이동합니다.

RC5는 빠져 있던 기존 설정 항목을 복원하고 저장값을 실제 기능에 연결했습니다. 전투 중 미니바 명령을 일괄 차단하던 처리를 제거했으며, 즉사 명령은 현재 시험 서버의 `Die.Command.Mode = 1` 설정과 함께 확인했습니다.

RC6는 퀘스트 시작·완료 NPC 연결 정보를 보완하고 실제 서버 배치 조회 후 이동하도록 수정했습니다. 퀘스트 목록에서 선택한 뒤 **시작 위치 / 종료 위치**를 누르세요. 현재 지도에서 가까운 NPC를 우선하며, 파티원 적용을 체크하면 도착 확인 후 해당 퀘스트를 가진 파티원을 소환합니다.

RC7은 **조건 찾기**를 연결했습니다. 미완료 목표의 몬스터·오브젝트 또는 수집 아이템 획득처를 찾아 실제 서버 배치로 이동합니다. 미완료 목표가 여러 개면 선택 목록이 나옵니다.

## RC8 편의 기능 변경

현재 실행 중인 SPP 명령 목록을 확인하여 지원하지 않는 명령을 교체했습니다. 기존 2열 편의 기능 화면은 유지합니다.

- **지도 개방:** 왼쪽 클릭은 미탐험 지역 지도 그림 표시, 오른쪽 클릭은 원래 가려진 지도 복원입니다. 서버 탐험 완료·경험치·업적·비행 경로는 바꾸지 않습니다. 지도 111개의 자료를 포함하며 돌발톱 산맥에서 실제 표시를 확인했습니다.
- **주변 리스폰:** 왼쪽은 대상 해제 후 주변 몬스터/오브젝트, 오른쪽은 선택한 죽은 몬스터입니다. 플레이어·소환수·살아 있는 몬스터는 오른쪽 실행에서 제외합니다. 숲거미를 처치한 뒤 두 방식 모두 실제로 살아나는 것을 확인했습니다.
- **캐릭터 탈출:** 이 SPP에서 지원하는 `.start`를 사용하며 실제 시전과 이동을 확인했습니다.
- **숙련 최대:** 이미 배운 전문기술만 현재 등급의 한도까지 올립니다. 새 기술이나 다음 등급을 자동으로 배우지 않습니다.
- **GM/직업/특성/전문기술 습득:** 지원하지 않는 전체 자동 습득 명령 대신 주문·조리법을 고르는 화면을 엽니다. GM은 전체 주문 검색, 특성은 본인 직업의 특성 주문 목록입니다. 주문 습득은 특성창의 특성 선택·활성화와 다릅니다. 전문기술의 미습득 조리법 보기 버튼은 필터를 적용합니다.
- 본인 전용 명령은 다른 사람에게 적용한다고 안내하지 않습니다. 다른 플레이어 레벨 변경은 서버가 요구하는 이름→증감값 순서를 사용합니다.

요청 전송만으로 성공 표시를 하지 않고 서버 응답을 확인할 수 있게 했습니다. `/gmbar audit`는 문제 확인용 명령 목록/도움말 조회이며 실제 게임 동작을 실행하지 않습니다.

## 설정과 즉사 서버 옵션

톱니바퀴 설정에서 창/미니바 크기, 퀘스트 도우미 자동 연결, 전투 중 GM 창 숨김, 전리품 자동 획득, 가방 자동 정렬, 통합 가방 사용, 상인 방문 시 회색 잡템 자동 판매를 바꿀 수 있습니다. 옵션은 즉시 반영되고 저장됩니다. 언어 변경은 UI 다시 불러오기가 필요합니다. 전리품 옵션은 블리자드의 실제 자동 획득 값과 동기화합니다. 통합 가방을 끄면 B 키가 기본 가방을 엽니다. 자동 판매는 기본 OFF이고 고정·퀘스트·판매 불가 아이템을 제외합니다.

대상 즉사는 `.die`를 한 번 전송합니다. SPP의 피해 계산 방식에서는 생명력이 남을 수 있으므로 서버 관리자가 `worldserver.conf`의 `Die.Command.Mode = 1`을 적용하고 `.reload config`로 다시 읽어야 합니다. 이번에 테스트한 사용자 PC에는 이미 적용했습니다. **ZIP에는 서버 설정 파일이 포함되지 않으므로 다른 서버에는 설정이 자동 적용되지 않습니다.** 보호된 창 열기·배치 변경·단축키 재지정은 전투가 끝난 뒤 수행합니다. 사전에 지정한 미니바 명령 실행은 전투 중에도 가능합니다.

## 설치와 실행

1. 게임을 종료합니다. 기존 `GMminibar`가 있다면 다른 곳에 보관합니다.
2. 압축 안의 `GMminibar` 폴더를 군단 클라이언트의 `Interface/AddOns`에 넣습니다.
3. 캐릭터 선택 화면에서 **GM MINI BAR[군단-SPP]**를 켭니다. 리치왕·MoP·터틀용 GMminibar를 같은 폴더에 섞어 넣지 마세요.
4. GM 권한이 있는 캐릭터로 접속하고 `/gmbar`를 입력합니다.

추가 MPQ, 서버 바이너리 교체, DB 수정이 필요하지 않습니다. 명령 실행 권한과 해당 명령의 지원 여부는 SPP 서버에서 결정합니다.

| 입력 | 기능 |
|---|---|
| `/gmbar` | GM 편의 기능 열기 |
| `/gmbar bags` | 통합 가방 열기 |
| `/gmbar quest` | 퀘스트 지도와 GM 퀘스트 도우미 열기 |
| `/gmbar test` | API·데이터·차단 오류 진단 |
| `/gmbar reset` | 미니바 위치·크기 초기화 |

설정 톱니바퀴에서 한국어/영어/클라이언트 언어 자동 선택을 바꾸고 UI를 다시 불러옵니다. 한국어와 영어 이외 클라이언트에서는 영어로 표시합니다. 게임의 단축키 설정에는 통합 가방과 GM 메뉴 항목이 추가됩니다. 기존 배낭/전체 가방 단축키(B 등)로 통합 가방을 엽니다. 원래 단축키 저장값과 블리자드 전역 가방 함수는 변경하지 않습니다.

## 화면과 기능

- **GM 편의 기능:** 수리, 재사용 대기시간 초기화, 전투 중지, 탈출, 탈것 내리기, 외형 복원, 수면 보행, 저장, 부활, GM·무적·비행, 레벨 ±1/±10, 지도 개방, 비행 경로 해제, 1,000골드, 숙련 최대, 즉시 시전, 자원 소모 해제, GM 주문·직업 주문·특성·전문기술, 소환, 대상에게 이동, 리스폰.
- 다른 캐릭터에 적용할 수 있는 편의 기능은 **왼쪽 클릭: 본인 / 오른쪽 클릭: 선택한 플레이어 또는 이름 입력**입니다. 소환·대상에게 이동은 다른 플레이어가 필요합니다. 서버가 이름 인수를 지원하지 않는 기능은 가까운 플레이어를 실제로 선택할 수 있어야 합니다.
- ON/OFF 기능은 버튼 하나로 전환 요청을 보냅니다. 버튼은 서버 상태를 확인하지 않고 현재 ON이라고 단정하지 않습니다. 서버 응답을 확인하세요.
- 편의 기능·주문·아이템·전문기술·순간이동 창은 1080×700 기준이며, 작은 화면에서는 비율을 줄입니다. 메뉴 제목은 비활성이고 설정 아이콘은 톱니바퀴입니다.
- **주문 검색:** 군단 DB2의 이름/ID/클래스/레벨 필터, 내 레벨 이하, 습득 주문 제외, 습득 상태 색상, 본인 대상 지정 후 배우기·삭제. 습득 여부는 서버 요청 직후 성공으로 처리하지 않고 클라이언트 주문 목록을 다시 확인합니다.
- **전문기술:** 14개 기술, 군단 800까지의 순차 등급 버튼, 현재 숙련도, 숙련 최대, 레시피 검색과 습득 표시, 가방 재료 수량. 낚시의 군단 단계는 기존 낚시 숙련 한도를 800으로 변경합니다.
- **아이템 검색:** 왼쪽 분류 트리, 오른쪽 2열 목록, 이름/ID·종류·품질·레벨 필터, 클릭 시 수량 입력 후 1~1,000개 지급. 던전·공격대 전리품과 세트 구성은 군단 DB2의 실제 관계로 분류합니다. 서버에 없는 아이템은 서버가 지급을 거절할 수 있습니다.
- **통합 가방:** 군단 기본 가방 버튼의 오른쪽 클릭 사용·왼쪽 클릭 이동·드래그·스택 분리 처리를 사용합니다. 선택 모드는 체크한 칸만 일괄 처리합니다. 아이템 고정은 해당 칸의 이동·사용·정렬·판매·파괴를 막습니다. 정렬 왼쪽 클릭은 즉시 정렬, 오른쪽 클릭은 자동 정렬 ON/OFF입니다. 판매/파괴는 품질·종류 선택 후 대상을 미리 확인하며, 고정 아이템과 판매할 수 없는 퀘스트 아이템은 판매에서 제외합니다. 실제 일괄 판매에는 열린 상인 창이 필요합니다.
- **퀘스트 도우미:** 조건 찾기, 조건 완료, 시작 위치, 종료 위치와 파티원 적용을 제공합니다. 조건 찾기는 미완료 목표의 NPC·오브젝트·아이템 획득처를 서버에서 조회하고 실제 배치로 이동합니다. 여러 목표는 선택 목록을 표시하며, 현재 지도에서 가까운 배치를 우선합니다. 시작·종료는 각각 제공자/완료 NPC로 이동합니다. 이동 성공 뒤 같은 퀘스트를 가진 연결된 파티원을 소환할 수 있습니다. 자료 불일치·누락·서버 배치 없음은 안내 후 멈춥니다. 스크립트 이벤트·화폐·평판 등 이동 대상이 없는 조건은 지원하지 않을 수 있습니다. 파티 이동과 모든 퀘스트는 게임 내 전수 검증하지 않았습니다.
- **GM 명령어:** 명령 예시를 선택·수정하여 전송하고 서버 응답을 확인합니다. 계정 확장팩 수준 변경처럼 인수가 필요한 명령은 여기서 입력할 수 있습니다.

검색 자료는 문자열 묶음으로 저장하고 여러 프레임에 나눠 검색합니다. RC2에서 2,000개 검색 제한을 제거했습니다. 결과는 작은 숫자 참조로 보관하고 화면에 보이는 행만 풀어 표시합니다. 상시 `OnUpdate` 검색이나 전체 레코드 테이블 생성은 하지 않습니다.

## 미니바 슬롯

왼쪽의 이동 손잡이를 잡아 위치를 바꾸고 오른쪽 한 칸의 +/−로 크기를 5%씩 조절합니다. 슬롯을 오른쪽 클릭하면 단축키를 지정합니다.

| 순서 | 슬롯 | 왼쪽 클릭 |
|---|---|---|
| 1 | GM 메뉴 | 편의 기능 |
| 2 | 은행 | GM 은행 명령. Ctrl+클릭하면 통합 가방 |
| 3 | 퀘스트 | 퀘스트 지도와 도우미 |
| 4 | 순간이동 | 목적지 검색 |
| 5 | 부활 | 본인 부활 요청 |
| 6 | GM | GM 모드 전환 |
| 7 | 무적 | 무적 전환 |
| 8 | 은신 | 은신 오라 적용/해제 |
| 9 | 대상 즉사 | 선택한 대상에 즉사 명령 |
| 10 | 비행 | GM 비행 전환 |
| 11 | 속도 | 기본/3배 이동 속도 전환 |

## 순간이동 자료

총 **833개 표시 항목**: 외부 포탈 착지 지점 131곳의 난이도별 항목, 제공 SPP 애드온의 도시·지역·직업 전당, 클라이언트의 비행 지점 422곳입니다. **전체·지역·도시·던전·공격대·전장**으로 분류하며 비행 조련사와 직업 전당은 지역에 포함됩니다. 일반/영웅/신화 및 지원 인원수를 목적지 이름에 표시합니다. 난이도 변경이 확인되지 않으면 이동을 취소합니다. 기본 레벨 오름차순, 열 제목 클릭 정렬, 대륙·지역 선택, 진영·즐겨찾기 필터를 제공합니다. 목적지 왼쪽 클릭으로 이동하고 오른쪽 클릭으로 즐겨찾기만 전환합니다.

던전·공격대 좌표는 만남의 돌 오브젝트 원점이 아니라 **WorldSafeLocs의 외부 포탈 착지 좌표**를 사용합니다. 비행 지점은 **TaxiNodes 좌표**이며, 전체 SPP DB의 NPC 스폰과 일치하는지는 아직 확인하지 못했습니다. 지역 표시는 명시된 비행 지점 지역명과 던전의 상위 지역 관계를 우선하고, 나머지는 지도 경계로 분류합니다. 권장 레벨은 던전·지역 자료를 우선하며 자료가 없으면 확장팩 진입 레벨로 표시합니다. RC2는 RC1의 이동 좌표를 변경하지 않습니다.

여관 자료는 아직 미포함입니다. RC6의 공개 퀘스트 시작·종료 관계 22,353개에 RC7의 목표 관계 17,822개 퀘스트·28,061개 목표를 추가했습니다. 좌표를 고정하지 않고 현재 SPP의 배치를 조회합니다. 서버 고유 퀘스트·위상·스크립트 조건과의 차이는 남아 있으며, 전체 동작 보장을 뜻하지 않습니다. 일반 `.go quest`는 잘못된 착지 확인 후 사용하지 않습니다.

## 현재 검증 결과와 남은 작업

2026-10-10 기준, Lua 5.1 문법 검사와 한국어·영어 각각 **270개 모의 API 동작 검사**를 통과했습니다. 모의 검사와 실제 게임 결과는 구분하여 기록합니다.

RC8은 지도 표시/복원, 숲거미 사망→생명력 2,212의 선택/주변 리스폰, 한 번 클릭 즉사, 캐릭터 탈출 이동, 직업/특성 주문 목록, 미습득 조리법 필터 및 이미 최대인 숙련도 안내를 확인했습니다. 진단 **24/24**, 시험 후 약 **34.9 MiB**, 이번 세션의 추가 오류 **0건**입니다. 캐릭터는 40레벨을 유지하고 원래 위치로 복귀했습니다. 이전 차단 오류 1건은 보존했습니다. 전체 명령·지도 111곳·파티·실제 숙련 증가를 전수 시험한 것은 아닙니다. 자세한 범위는 [GAME_TEST.md](GAME_TEST.md)를 참조하세요.

RC7에서는 **해방의 날의 족쇄 오브젝트**, **마지막 식사의 사슴 획득처**, 종료 NPC 복귀를 실제 확인했습니다. 지면에 선 모습과 도착/근처 도착 표시를 확인했고 진단은 **24/24**, 메모리는 약 **36.9 MiB**입니다. 누적 Hide 차단 오류 1건을 보존했으며 Escape 경로 수정 후 마지막 전투 재검증 세션의 추가 오류는 0건입니다. 퀘스트 완료·보상은 실행하지 않았습니다. 아래 RC6 이하 결과는 이전 버전의 시험 기록입니다.

RC6에서 퀘스트 14098의 시작·종료, 14093의 종료 위치 이동과 도착 표시를 확인했습니다. NPC에서 걸어 나온 뒤 버튼으로 돌아오는 동작과 지면 상태를 확인했고, 진단 **23/23**, 기록 오류 **0건**입니다.

RC5에서는 배율·퀘스트 연결·기본 가방 전환·자동 전리품·UI 재로딩 후 저장값을 확인했습니다. 실제 전투 중 즉사 단축키 한 번으로 훈련용 허수아비를, 즉사 버튼 한 번으로 순찰자를 처치했습니다. 비행 ON/OFF와 GM 모드, 전투 시작/종료 시 창 숨김·복원도 확인했습니다. 자동 잡템 판매는 모의 검사까지만 수행했습니다.

RC4에서 가방 전체 배치, B 키, 고정 보호, 물약 실제 사용(2→1), 선택 표시, 파괴 대상 미리보기와 취소, 고정 위치를 유지하는 자동/수동 정렬을 확인했습니다. 재접속 없이 UI 새로고침 후 진단은 **22/22**, 초기 메모리 **29.9 MiB**, 기록된 오류 **0건**입니다. 일괄 판매·파괴의 실제 실행과 Shift+클릭/드래그 제스처는 게임 내 미검증이며 모의 검사 결과와 구분합니다.

사용자가 실행한 **7.3.5.26972 32비트 한국어 클라이언트와 SPP 2026.2a**를 직접 조작했습니다. RC2에서 필사의 일격 12294 검색·습득·습득 취소와 상태 갱신, 아이템 전체 검색 103,892건·2열 배치·수량 창·물약 1개 지급, 순간이동 표·난이도 표시·정렬, 전문기술 75/75와 다음 등급 활성 상태, 작은 창의 메뉴 배치를 확인했습니다. 기본 API·데이터 진단은 **22/22**, 초기 메모리는 약 **29.8 MiB**였습니다. 이전 RC1에서 확인한 가방 사용·장착, 비행, 일부 착지·난이도 전환, 언어 전환 결과와 이번 재검증 범위는 [GAME_TEST.md](GAME_TEST.md)에 구분했습니다.

테스트 중 발견한 레시피 습득 표시 갱신, 창 겹침, 작은 화면의 퀘스트 도우미 가림, 저장 아이콘·손잡이 표시를 수정했습니다. 모든 명령·전문기술 등급·833개 이동 항목과 전투 중 사용, 탈것 상태 착지, 다중 캐릭터 동작을 전부 검증한 것은 아닙니다. 퀘스트 시작·종료 관계 자료의 서버별 차이와 위상별 배치는 전체 검증 범위에 포함되지 않습니다.

`GMMLegionDiagnostics` SavedVariables에는 최근 차단 오류와 진단 결과가 저장됩니다. 진단 통과만으로 실제 명령 성공이나 착지 성공이 확인되는 것은 아닙니다.
