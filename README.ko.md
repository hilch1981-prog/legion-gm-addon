## 설치와 실행

1. 위의 **설치 ZIP**을 받고 게임을 종료합니다. 기존 `GMminibar` 폴더가 있다면 다른 곳에 보관합니다.
2. 압축 안의 `GMminibar`를 군단 클라이언트의 `Interface/AddOns`에 넣습니다.
3. 최종 경로가 `Interface/AddOns/GMminibar/GMminibar.toc`인지 확인합니다.
4. 캐릭터 선택 화면에서 **GM MINI BAR[군단-SPP]**를 켜고, 필요한 GM 권한이 있는 캐릭터로 접속합니다.
5. 미니바의 **GM 메뉴**를 누르거나 `/gmbar`를 입력합니다.

GitHub의 자동 생성 **Source code** 압축 파일은 개발용입니다. 일반 설치에는 이름이 표시된 설치 ZIP 하나만 사용하세요. 설정을 유지하려면 `WTF`를 지우지 마세요. GM 권한과 명령 지원 여부는 서버에서 결정하며, 애드온 설치가 GM 권한을 부여하지는 않습니다.

문서 상단의 **English / 한국어**로 설명글 언어를 바꿉니다. 게임에서는 톱니바퀴 설정에서 **자동·한국어·영어**를 선택한 뒤 UI를 다시 불러옵니다. 자동은 클라이언트 언어를 따르며, 한국어·영어 외의 클라이언트에서는 영어로 표시합니다. 현재 군단용 UI의 지원 언어는 한국어와 영어입니다.

### 편의 기능 조작과 RC8 변경 사항

- 다른 플레이어를 지원하는 기능은 **왼쪽 클릭: 본인**, **오른쪽 클릭: 선택한 플레이어 또는 이름 입력**입니다. 서버가 가까운 플레이어의 실제 선택을 요구하는 기능은 그 조건을 따릅니다. 본인 전용 기능은 별도로 표시합니다.
- **리스폰:** 왼쪽 클릭은 보안 클릭으로 대상을 해제하고 주변 리스폰을 요청합니다. 오른쪽 클릭은 선택한 죽은 몬스터에 적용하며, 플레이어·소환수·살아 있는 대상은 거부합니다.
- **지도 개방:** 왼쪽 클릭은 클라이언트에 있는 지도 그림을 표시하고, 오른쪽 클릭은 원래 안개 표시로 돌립니다. 탐험 경험치·업적·비행 경로 습득을 부여하지 않습니다. 지도 111개·표시 영역 1,521개의 자료를 포함하며, 실제 게임 확인은 일부 지도에서 수행했습니다.
- **캐릭터 탈출**은 해당 SPP 서버가 지원하는 `.start`를 사용합니다.
- **숙련 최대**는 이미 배운 전문기술 중 현재 한도에 못 미치는 기술에만 `.setskill`을 적용합니다.
- 해당 SPP에 없는 일괄 습득 명령은 주문 선택 목록으로 연결했습니다. GM·직업·특성 버튼은 주문 목록을 열고, 전문기술은 미습득 제작법을 필터링합니다. GM 목록은 전체 주문 검색이며, 특성 주문 습득과 특성창의 선택·활성화는 다릅니다.
- 요청 전송과 서버 응답을 구분합니다. 명령을 보냈다는 이유만으로 성공했다고 표시하지 않습니다.

### 통합 가방과 미니바 슬롯

기존 가방 키인 **B**, `/gmbar bags`, 또는 **은행 슬롯 Ctrl+클릭**으로 엽니다. 통합 창 안에서 장착 가방 4칸을 사용할 수 있습니다. 물약 등 아이템 사용은 군단 기본 가방 처리 방식을 이용합니다. 고정 칸은 정렬·일괄 작업에서 보호하며, 판매·파괴에는 대상 미리보기를 제공합니다.

![통합 가방 조작부와 미니바](docs/images/10-rc4-bag-controls.png)

*RC4 촬영: 화면 오른쪽의 통합 가방 조작부와 아래쪽 미니바입니다.*

미니바 왼쪽 손잡이로 위치를 이동하고 오른쪽 한 칸의 **+/−**로 크기를 5%씩 바꿉니다. **미니바 슬롯 오른쪽 클릭은 단축키 지정**입니다. 다른 플레이어를 지정하는 편의 기능 버튼의 오른쪽 클릭과 구분됩니다.

| 3 · 퀘스트 | 퀘스트 지도와 도우미 |

### 순간이동

![난이도별 목적지와 정렬 열이 있는 순간이동 목록](docs/images/03-teleport-table.png)

*RC2 촬영: 공격대 목적지, 난이도·인원 표시와 정렬 가능한 표입니다.*

분류는 **전체·지역·도시·던전·공격대·전장**입니다. 비행 지점과 직업 전당은 지역에 포함합니다. 기본은 권장 레벨 오름차순이며, 목적지를 왼쪽 클릭하면 이동하고 오른쪽 클릭하면 즐겨찾기를 바꿉니다.

던전·공격대는 **WorldSafeLocs의 외부 포탈 착지 좌표 131곳**을 난이도별로 표시합니다. 난이도 변경이 확인된 뒤 이동합니다. SPP 도시·지역·직업 전당과 **TaxiNodes 비행 지점 422곳**도 포함합니다. 모든 비행 지점이 실제 SPP NPC 배치와 일치하는지는 확인하지 못했습니다. **여관 자료는 아직 미포함**이며, 모든 목적지·탈것 상태 착지·난이도 조합을 시험한 것은 아닙니다.

공개된 퀘스트 관계 자료와 실제 서버 조회 응답으로 시작·종료 NPC 및 목표 위치를 찾습니다. 목표가 여러 개면 선택 목록을 표시하고, 현재 지도에서 가까운 배치를 우선할 수 있습니다. 자료나 서버 응답을 해석할 수 없으면 좌표를 추측하지 않고 멈춥니다.

**파티 적용 옵션**은 이동 후 같은 퀘스트를 가진 연결된 파티원을 소환할 수 있습니다. 모의 검사는 있으나 실제 다중 플레이어 시험은 수행하지 않았습니다. 스크립트 이벤트·위상·서버 고유 퀘스트는 참조 자료와 다를 수 있습니다. 시작·종료 관계 22,353개 퀘스트, 목표 관계 17,822개 퀘스트·28,061개 목표를 포함하며, 모든 퀘스트의 지원을 뜻하지 않습니다.

## 검증 결과와 남은 범위

최근 호환성 확인은 **2026-10-12**입니다. RC8의 한글 응답 실패를 재현한 뒤, RC8.1에서 퀘스트 27168의 **종료 위치·조건 찾기·시작 위치가 모두 실제 NPC 앞으로 이동**했습니다. 진단 **24/24**, 이번 시험 세션 오류 **0건**입니다. 원래 위치로 복귀했고 퀘스트 진행 수치는 그대로이며 이동 중 탐험 경험치 376이 발생했습니다. 한글 오브젝트 응답은 모의 검사 범위이고, 모든 퀘스트나 다른 사용자의 PC를 확인한 것은 아닙니다.

이전 RC8 게임 확인은 **2026-10-10**, **SPP 2026.2a / 32비트 한국어 7.3.5.26972 클라이언트**에서 수행했습니다. RC8은 지도 그림 표시·복원, 선택한 죽은 몬스터와 주변 몬스터 리스폰, 한 번 클릭 즉사, 탈출 이동, 직업·특성 목록, 미습득 제작법 필터, 이미 최대인 숙련도 안내를 확인했습니다. 진단 **24/24**, 해당 시험 세션의 추가 오류 **0건**이며, 이전 차단 오류 기록 1건은 보존했습니다.

RC2~RC7에서는 일부 주문 습득·삭제, 아이템 지급, 물약 사용, 가방 조작, 설정 유지, 전투 중 단축키, 특정 퀘스트의 조건·시작·종료 위치 이동을 확인했습니다. 이는 이전 버전의 시험 기록이며 전체 기능을 RC8에서 다시 확인했다는 뜻은 아닙니다. 세부 내역은 [게임 테스트 기록](GMminibar/GAME_TEST.md)을 참고하세요.

자동 검사는 **Lua 14개 문법**, 한국어·영어 각각 **295개 모의 API 검사**를 수행합니다. 자동 검사에서는 게임이나 서버를 실행하지 않습니다. 전체 명령, 모든 순간이동 착지, 전문기술 등급 증가, 파티 기능 등의 전수 검증은 남아 있습니다.

오류 제보에는 애드온·클라이언트·서버 버전, 사용한 기능, 주문·아이템·퀘스트 또는 목적지 ID, 진단·오류 문구를 적어 주세요. 계정 비밀번호나 정리되지 않은 `WTF` 폴더는 첨부하지 마세요.

## 개발·출처·라이선스

```sh
python -m pip install -r requirements-dev.txt
python scripts/validate.py
python scripts/package.py
```

Python 3.12를 CI에서 사용합니다. `addon-manifest.json`으로 소스 파일의 해시를 검사하고 `dist/`에 단일 폴더 ZIP을 생성합니다. [release.json](release.json)에 v1.0.0 배포 해시와 실게임 시험본의 관계를 기록합니다. 버전명 변경을 전체 기능의 새 실게임 검증으로 간주하지 않습니다.

생성된 Lua 검색 자료가 포함되어 게임 중 DB 연결이 필요하지 않습니다. 상위 출처, 자료 형식 해시와 생성 이력은 [SOURCES.md](GMminibar/SOURCES.md)에 있습니다. 그 문서의 `work/legion-audit` 경로는 원래 자료 생성 작업 공간의 기록이며, 해당 오프라인 도구와 클라이언트 원본 압축 파일은 이 저장소에 포함하지 않습니다.
